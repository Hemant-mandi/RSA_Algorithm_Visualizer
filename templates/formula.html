RSA FORMULAS

Mathematical foundations of the RSA cryptosystem

01
Choose Two Large Primes
$$p, \; q \in \mathbb{P}, \quad p \neq q$$

Select two distinct large prime numbers p and q. The security of RSA relies on the difficulty of factoring their product n. In practice, both primes should be of similar bit-length.

Example: p = 61,   q = 53
02
Compute the Modulus n
$$n = p \times q$$

The modulus n is the product of the two primes. It forms part of both the public and private keys. Its bit-length is the key size (e.g., 2048 bits for modern RSA).

Example: n = 61 × 53 = 3233
03
Compute Euler's Totient φ(n)
$$\varphi(n) = (p - 1)(q - 1)$$

Euler's totient function φ(n) counts integers from 1 to n that are coprime with n. For a semiprime n = pq, this simplifies to (p−1)(q−1). This value is kept secret.

Example: φ(3233) = 60 × 52 = 3120
04
Choose Public Exponent e
$$1 \lt e \lt \varphi(n), \quad \gcd\!\bigl(e,\,\varphi(n)\bigr) = 1$$

The public exponent e must be coprime with φ(n). Common choices are 65537 (0x10001) in production systems, as it is a Fermat prime and allows fast exponentiation. Together with n, it forms the public key (e, n).

Example: e = 17   (gcd(17, 3120) = 1 ✓)
05
Compute Private Exponent d
$$d \equiv e^{-1} \pmod{\varphi(n)}$$

The private exponent d is the modular multiplicative inverse of e modulo φ(n), i.e., de ≡ 1 (mod φ(n)). It is computed using the Extended Euclidean Algorithm. Together with n, it forms the private key (d, n).

Example: d = 2753   (17 × 2753 mod 3120 = 1 ✓)
06
🔒 Encryption
$$C \equiv M^e \pmod{n}$$

To encrypt a message M (an integer where 0 ≤ M < n), raise it to the public exponent e modulo n. The result is the ciphertext C. This uses fast modular exponentiation.

Example (M = 65 → 'A'): C = 6517 mod 3233 = 2790
07
🔓 Decryption
$$M \equiv C^d \pmod{n}$$

To decrypt ciphertext C, raise it to the private exponent d modulo n. By Euler's theorem this recovers the original message M.

Example: M = 27902753 mod 3233 = 65 → 'A' ✓
🗝️

Key Summary

Public Key
$(e,\; n)$

Shared openly. Used to encrypt messages.

Private Key
$(d,\; n)$

Kept secret. Used to decrypt messages.

🛡️

Security Basis

RSA security relies on the Integer Factorization Problem: given a large composite number n = pq, it is computationally infeasible to factor it back into p and q in polynomial time (no known efficient classical algorithm exists). Breaking RSA would therefore require factoring n — something believed to take millions of years even for modern supercomputers with 2048-bit keys.

Best Classical Attack
General Number Field Sieve
$O\!\left(\exp\!\left(c\,(\log n)^{1/3}(\log\log n)^{2/3}\right)\right)$
Quantum Threat
Shor's Algorithm
$O\!\left((\log n)^3\right)$ — breaks RSA on a quantum computer
